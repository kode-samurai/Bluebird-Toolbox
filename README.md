# 🛠️ 青鸟工具箱 · Bluebird Toolbox

> 不要温和地走进那个良夜  
> 一个 **纯粹、克制、注重体验** 的在线工具集合

**青鸟工具箱** 是一个面向普通用户与开发者的综合在线工具站。  
无需登录、无需安装、打开即用。

🌐 在线访问：http://www.codesamurai.top  
☕ Bug / 建议反馈：站点右上角「咖啡」按钮

## ✨ 为什么是青鸟工具箱？


- 🎯 **只做工具，不打扰你**  
  无广告、无弹窗、不收集隐私信息

- 🧩 **模块化设计**  
  每个工具独立、风格统一，持续可扩展

- 🚀 **长期维护**  
  新工具与体验优化会持续加入

---

## 🧰 已上线工具（节选）

- 随机数 / 随机字符串 / 抽奖轮盘  
- 进制转换 / 单位换算 / BMI 计算  
- JSON 格式化 / 大小写转换  
- 时间戳 / 日期间隔 / 年龄计算  
- 网络信息（IP / User-Agent）

> 未上线或规划中的工具会显示占位页

---

## 🖥️ 技术栈

- **Frontend**：Vue 3 + Vite  
- **Backend**：Django 5 + REST API  
- **Style**：统一 `global.css`，支持主题切换  
- **HTTP**：Axios 封装（含全局错误处理）

> 当前版本暂不提供 SDK / API 文档
