# Changelog

> 项目持续迭代中，以下记录主要功能上线、问题修复及待优化事项。

---
## Alpha Version

## ✅ 已上线（Features）

### 🧰 工具功能
- 随机数生成
- 随机字符串生成（支持强度提示、批量生成、复制）
- 抽奖转盘（支持单个 / 批量添加、动画滚动）
- JSON 格式化
- 大小写转换
- 颜色转换
- 时间戳转换
- 进制转换（2–64 进制，实时校验）
- 存储单位换算
- 数据速率换算
- 通用单位换算
- BMI 计算
- 日期间隔计算
- 年龄计算
- Fibonacci 数列
- 区间素数计算
- 奇偶求和
- 网络信息查询（IP / User-Agent）

### 🎨 UI & 体验
- 全站深色 / 浅色模式
  - 自动跟随系统主题
  - 顶部按钮手动切换
- 基于 `global.css` 的统一设计体系
  - 输入框 / 按钮 / 卡片 / 复选框统一样式
  - 所有工具页一键主题切换

### 🧭 页面与结构
- Home 工具导航页
- 404 页面（页面不存在）
- 500 / 接口错误页面
- 工具未上线占位页面
- Feedback 页面（预留反馈入口）

---

## 🛠 已解决（Fixed）

- 修复深色 / 浅色模式下文字对比度不足问题
- 修复白天模式下结果文本不可见的问题
- 统一 `input[type=number]`、`checkbox`、`select` 样式
- 修复 `tool-select` 与 `tool-input` 高度不一致、错位问题
- 顶部主题按钮与反馈按钮重叠问题
- User-Agent 在移动端无法完整查看的问题（改为多行展示）
- Axios 接口异常统一处理与错误页跳转
